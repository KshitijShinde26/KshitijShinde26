## 🚀 Featured Backend Project

### [Surplus Food Marketplace Backend](https://github.com/KshitijShinde26/Surplus_Food_MarketPlace_Project)
> **Enterprise Java REST API platform connecting food businesses with consumers and NGOs to reduce food waste through transactional commerce and donation pipelines.**

- **Architecture:** Layered modular backend using **Java 21** and **Spring Boot 3.3.5**.
- **Authentication & Security:** Stateless **JWT (JSON Web Token)** filter chain integrated with **Spring Security** enforcing strict role-based access control (`ROLE_CONSUMER`, `ROLE_BUSINESS`, `ROLE_NGO`, `ROLE_ADMIN`).
- **Data Persistence:** Relational schema design on **MySQL InnoDB** managed via **Spring Data JPA / Hibernate**, featuring transactional consistency with `@Transactional` boundaries, automated rollback handling, and optimized entity relations.
- **RESTful Endpoints:** Comprehensive API layer handling listings, multi-tier orders, donations, ratings/reviews, dispute resolutions, and analytics aggregation with Jakarta (`JSR-380`) validation.
- **Event-Driven & Real-Time:** Custom event publishers (`ApplicationEventPublisher`) coupled with transactional listeners and **WebSocket** infrastructure for real-time notification dispatching.
