## 🚀 Featured Project

### 🛒 [Surplus Food Marketplace Backend](https://github.com/KshitijShinde26/Surplus_Food_MarketPlace_Project)

An enterprise-style Java Spring Boot backend for a surplus food marketplace connecting food providers, consumers, and NGOs to help minimize food waste.

**Core stack:** Java 21, Spring Boot 3.3.5, Spring Security, JWT, Spring Data JPA, Hibernate, MySQL, WebSockets/STOMP, and Maven.

#### Backend Architecture & Highlights
- **Layered architecture:** Controllers, Services, Repositories, Entities, DTOs, and Mappers.
- **Security & authorization:** Stateless JWT authentication and role-based access control for consumers, businesses, NGOs, and admins.
- **Data persistence:** MySQL with Spring Data JPA and Hibernate.
- **Transactions & pooling:** Transaction boundaries and database connection pooling.
- **Real-time notifications:** WebSockets/STOMP for live alerts.
- **Validation & monitoring:** Request validation and Actuator health endpoints, as implemented in the project.

**[View Repository →](https://github.com/KshitijShinde26/Surplus_Food_MarketPlace_Project)** · **[Live App Preview →](https://surplus-food-market-place-project.vercel.app)**
